What is Let's Chat?

Let's Chat is a Monday.com board view that turns any board into a real-time team chat room. Your team can send messages, reply in threads, mention teammates, and stay in sync—all inside Monday.com, no extra tools needed.

🎯 How It Works

Install Let's Chat from the Monday.com marketplace, open any board, add the view from the Views Center, and your team has an instant chat room tied directly to that board. Messages are live, threaded replies keep conversations organized, and role-based access keeps your workspace secure.

⚡

Real-Time Messaging

Messages appear instantly for all board members. No refresh needed—powered by WebSockets for seamless live communication.

🧵

Threaded Replies

Keep discussions organized with threads. Reply to any message to start a focused side conversation without cluttering the main chat.

👥

Team Sidebar

See who's in the chat room at a glance. The sidebar lists all active board members so you always know who's available.

🌙

Dark Mode Support

Automatically adapts to your Monday.com theme. Works beautifully in both light and dark modes for comfortable all-day use.

Powerful Features

💬 Live Chat Room

Every board gets its own dedicated chat room. Team members can send messages, share updates, and collaborate in real time without leaving Monday.com.

  • Real-time message delivery via WebSockets
  • Persistent message history for full context
  • Board-scoped rooms keep conversations relevant
  • Works on desktop and mobile browsers

🧵 Threaded Conversations

Reply to any message to open a side thread. Keep long discussions from cluttering the main timeline while preserving the full conversation context.

  • Thread reply panel opens alongside main chat
  • Thread count indicator on each message
  • Notifications for new thread replies
  • Collapsible threads for a clean interface

👤 User Mentions

Tag teammates with @ mentions to grab their attention. Mentioned users receive a notification instantly so nothing gets missed.

  • @ mention any board member
  • Instant in-app notification on mention
  • Highlighted mention in message thread
  • Works in both main chat and thread replies

🔒 Role-Based Access

Access is tied directly to Monday.com board membership. Viewers and guests are restricted, and admins retain full control over who can participate.

  • Only board members can send messages
  • Viewers/guests see a friendly upgrade prompt
  • Admin-controlled plan upgrades via Monday.com
  • Secure re-authentication on account changes

How to Get Started

You'll be chatting with your team inside Monday.com in under 5 minutes. Follow these 4 simple steps.

1

🛒 Install from the Marketplace

Search for "Let's Chat" in the Monday.com App Marketplace and click Install. Or use the direct install button below — the app will be added to your account instantly.

2

🔐 Agree on Auth Permissions

Review and approve the required permissions. Let's Chat only requests access needed to identify board members and deliver real-time messages securely.

3

📋 Go to Any Board

Open any board in your Monday.com account where you'd like to enable team chat. You can add Let's Chat to as many boards as your plan allows.

4

👁️ Open the Views Center & Add the View

Click "Views Center" at the top of the board, search for "Let's Chat", and add it. Your chat room is live immediately — invite your team and start messaging!

✅

Ready to Chat

No servers to configure, no external accounts to create. Let's Chat runs entirely inside Monday.com using your existing account and board structure.
